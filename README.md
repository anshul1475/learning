
 Food Market Website

A modern and responsive **Food Market Website** built using **HTML, CSS, and JavaScript**. This project showcases a stylish food ordering interface with interactive UI elements and a user-friendly design.


 Features

 Responsive Homepage Design
 Food Categories & Menu Display
 Add to Cart Functionality
 Search Food Items
 Mobile-Friendly Layout
 Attractive UI with CSS Styling
 Interactive Features using JavaScript

 Technologies Used

HTML5 – Structure of the website
CSS3 – Styling and layout
JavaScript (JS) – Interactivity and dynamic behavior

 Project Structure


food-market/
│
├── index.html        # Main HTML file
├── style.css         # Styling file
├── script.js         # JavaScript functionality
├── images/           # Images used in project
└── README.md         # Project documentation
